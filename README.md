📱 Present Me

📖 Overview

**Present Me** is an iOS application created as part of the **Apple Developer Academy** journey. 
The goal of this project is to introduce who I am, highlight my passions, skills, and background, and turn a traditional personal introduction into an interactive mobile experience.

---

🛠️ Tech Stack

- **Language:** Swift
- **UI Framework:** SwiftUI
- **IDE:** Xcode
- **Design & Prototyping:** Sketch
